# LMGAMES-first
C++编码的一款以王橹杰为主角视角的一款文字修仙小游戏，目前只能在本地窗口运行，下一个项目预计使用C++加JS或py加JS的方式制作一个网页版的小游戏，或者学习一下Lua，用Lua进行开发，再接下来学习制作H5小游戏，或抖音小游戏或微信小游戏，哪个便宜做哪个，这阶段就要增加一些美术资源，还要提高一下我的画画能力好吧。再接下来采用unity制作一个功能完善的DEMO。再接下来，使用AI辅助游戏开发。 源代码中各个部分的代码都有相关的注释，要修改可以找到对应的地方去修改

我没有将这个文字小游戏做成网页形式的，因为我觉得web的开发太无聊了，这不是我喜欢的。所以没做成，但是，我用豆包将原先的代码做了一个简单的页面框架，采用python ui 加C++ 内核的形式，我也发现了像豆包这类ai在code方面的缺陷，它无法完全理解你真正想要的是什么，也可能是国内大模型现在还不够完善，我的电脑现在用其他ai可能会飞起来，毕竟豆包有时候都卡死我了。言归正传，在用豆包形成简单架构之后，我又进行了很长一段时间的修改，因为豆包把好一些内容删除了，还有很多的错字和数值方面的错误，比如闪避系统，加点系统，敌人属性变更错误，出现左脚踩右脚螺旋升天的问题，我花了点时间才把这些加回去了，哦，对了，还有页面ui方面也有很大的问题，我也进行了调整。
我觉得，ai目前来看无法完全取代程序员，正如我们专业主任在我们系院第一节课上所说的那样，ai使得从0到1之间的壁垒消失了，当今时代更重要的是如何从1到100，对于程序员来说，ai是一个非常好用的一个辅助工具，它极大的减少了花费在一些重复性任务的时间，使得程序员能够更多地把时间精力花在更加重要的模块上，使得一个程序员能发挥出过去好几个人的效果。
